USER INSTRUCTIONS
=================

Provide users with this simple guide:

---
INSTALLATION GUIDE

1. Requirements:
   - Ubuntu 20.04+ or Debian 11+ server
   - Root/sudo access
   - Domain name pointing to your server
   - 1GB RAM, 2GB disk space minimum

2. Download & Extract:
   wget [URL-TO-YOUR-ARCHIVE]
   tar -xzf boat-tracker-installer.tar.gz
   cd boat-tracker_installer

3. Run Installer:
   sudo bash install.sh

4. Follow the prompts:
   - Enter your domain name
   - Choose SSL option (Let's Encrypt recommended)
   - Optionally add weather API key
   - Confirm installation

5. Access:
   Visit https://your-domain.com
   Login with credentials shown at end of installation

Complete documentation in README.md
